# AGUI documentation

Learn how to use AGUI to create and work with interactive interfaces alongside your AI agent. Start with the [project README](../README.md) for an introduction and setup, or explore the guides below for more detail.

- [AGUI reference](./reference.md): session manager, CLI controls, the floating data toolbar, manual JSON transfer, data-flow metadata, saved interfaces, internet sharing, optional MCP integrations, and troubleshooting.
- [Team AGUI libraries](./library.md): organize reusable interfaces across projects and team checkouts, manage storage scopes, and share definitions through Git.

For agents creating interfaces, the [AGUI skill](../skills/symbiote-agui/SKILL.md) covers interface generation, Symbiote patterns, and tool invocation.
