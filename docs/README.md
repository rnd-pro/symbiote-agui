# AGUI documentation

Learn how to use AGUI to create and work with interactive interfaces alongside your AI agent. Start with the [project README](../README.md) for an introduction and setup, or explore the guides below for more detail.

- [AGUI reference](./reference.md): session manager, CLI controls, the floating data toolbar, manual JSON transfer, data-flow metadata, saved interfaces, public asset proxy, internet sharing, optional MCP integrations, and troubleshooting.
- [Team AGUI libraries](./library.md): organize reusable interfaces across projects and team checkouts, manage storage scopes, and share definitions through Git.
- [App templates](../templates/README.md): choose a starter, configure its data and appearance, and evolve the saved app without regenerating its shell.
- [Local session assets](./assets.md): publish original files, use portable page URLs, and review lifecycle and sharing boundaries.
- [Standalone UI library](../uilib/README.md): use the components and Symbiote HTML-app in an existing project or directly from a browser/CDN module, without an AGUI worker. Start with the [HTML example](./examples/standalone.html).

For agents creating interfaces, the [AGUI skill](../skills/agui/SKILL.md) covers interface generation, Symbiote patterns, and tool invocation.
