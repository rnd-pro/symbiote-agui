# AGUI documentation

Learn how to use AGUI to create and work with interactive interfaces alongside your AI agent. Start with the [project README](../README.md) for an introduction and setup, or explore the guides below for more detail.

- [AGUI reference](./reference.md): session manager, CLI controls, saved interfaces, internet sharing, optional MCP integrations, and troubleshooting.
- [Team AGUI libraries](./library.md): configure a shared folder, discover and describe interfaces, and sync definitions shared through Git. Explains storage scope and what is preserved when sessions stop or clear.

For agents creating interfaces, the [AGUI skill](../skills/symbiote-agui/SKILL.md) covers interface generation, Symbiote patterns, and tool invocation.
