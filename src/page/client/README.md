# Browser interfaces

`npx symbiote-agui start <SESSION_ID>` opens the page automatically. With `--no-open`, open the returned `url` directly. The browser connects by WebSocket without an authorization request, cookie, or token link.

Tab titles come from the session ID in the page URL. A shared emoji palette provides a stable per-ID SVG favicon across local and shared pages. Page connection and content updates restore this identity independently of generated headings.

In shared sessions, the first eligible connection is the user and other pages are viewers. After the user disconnects, the next eligible connection or reconnection can take the role. Explicit viewer links remain read-only. Viewer pages display a sandboxed, inert snapshot of the user's light DOM and form values. They run no generated modules and expose no tools. Snapshots are coalesced, bounded to 1 MiB, and retain each viewer's scroll position. Local-only pages receive markup and state updates independently while the session runs. Reload restores the latest accepted markup with its initial component state. A local interactive reconnect retains its DOM, drafts, module instances, and connector request references when the known worker identity and complete accepted render match. A changed render or unknown worker restores the current definition instead. Public user pages restore their definition on reconnect; viewers return to the current mirrored view.

Use the [UI library foundations](../../uilib/README.md) for `<sym-component>` inline RAT markup, context providers, and reusable DOM templates through `use-template`. Declare reusable custom tags with native `sym-component reg="..."` and a direct template or `use-template`. Register custom subclasses through Symbiote's `reg()` so WebMCP receives their tag identity. Definitions persist for the page lifetime; each insertion supplies fresh instances and templates.

The JSDA entry registers the generic [UI library](../../uilib/README.md), then its page-owned data toolbar, connector, and preference-saving subclasses before connecting. `templates.js` supplies the AGUI-only templates alongside the library aggregate for style compilation. Session-aware content replacement, transport events, feedback guards, and proxy response metadata stay in this client. The generic library exposes DOM action events; one page listener forwards them through the worker connection. Foundation components render in light DOM and accept primitive attributes, standard Symbiote property bindings, and native `$` object-merge bindings. Each primitive owns its local state by default; use a common provider for shared application data rather than per-control JSON. Component templates are included as Tailwind candidates by `createStyles()`, and shared design tokens come from `uilib.css`. Colocated component styles use native `rootStyles`; adopted stylesheets are included in inert viewer snapshots. Keep ordinary component usage self-contained in SKILL.md; do not add per-task imports or registration steps.

Application copy belongs outside uilib. `page-text.js` registers common toolbar state in native `AGUI_TEXT/dataToolbar`; pass it with `bind="$: AGUI_TEXT/dataToolbar"` or supply an application-owned `{ texts: { ... } }` object. Other components take text attributes or bindings. Components never supply language-specific fallback copy.

Opt into executable code with `<script type="module" data-agui>`. Module-scope code runs before mounting so it can register component classes. An optional default export receives `(root, { emit, submitFeedback })` after mounting and may return a cleanup function for replacement or stop. Other executable scripts remain inert. Import the fully resolved URL `new URL('/client/index.js', location.href).href` for the exported Symbiote APIs. `emit()` buffers ordinary named JSON events for CLI collection; it never invokes the private feedback handler.

Use `submitFeedback(event, { userEvent, submissionId?, revision? })` only from a trusted native click or submit handler after local validation. It consolidates the application's context into one payload and resolves when delivery is accepted, rejected, or unknown. The reserved native context `AGUI_FEEDBACK` provides availability and UI status/message bindings without another sym-context. Module restoration, agent-driven commands, and reused or synthetic user events cannot submit. Reconnects read receipts rather than replay payloads. See the [feedback contract](../../../docs/reference.md#explicit-browser-submissions) for correlation and persistence boundaries.

Event bindings automatically expose Symbiote tools. Import `ToolDescriptor` for explicit actions, or `getActiveWebMCPTools` and `webMCPRegistry` for registration diagnostics. Initialize descriptors in `init$` before rendering and declare `deps` for conditional visibility. Use CLI `tools` and `call` or optional AGUI MCP to discover and invoke tools over the existing WebSocket; native browser WebMCP is optional. Replacement and stop remove generated components and their tools while tabs remain open. See the [Symbiote WebMCP guide](https://github.com/symbiotejs/symbiote.js/blob/main/docs/webmcp.md) for an explicit tool example.

The browser entry and manager observe promises returned by native `registerTool()`, preserving their return values. Cancellation of an aborted registration is handled locally; other asynchronous registration failures are reported to the console. This compatibility guard leaves Symbiote's registry, execution, and signal-driven cleanup in charge.

Browser-side integrations can import `listPageTools()` and async `executePageTool(name, input = {})` from `/client/index.js`. These forward Symbiote's public metadata and execution results, including `isError` responses, without requiring native WebMCP. Validate inputs against the discovered schemas before invocation. Tool availability follows Symbiote's visibility and component lifecycle.

HTML-app owns JSON defaults, actions, context ownership, object writeback, imports, conditions, and outgoing mappings. A named `sym-context` uses one native store for local and named fields. Declare owners before sibling consumers; session replacement detaches and destroys old owners before mounting their replacements. Native `$` object input merges without echoing or deleting omitted fields; optional `pub-to` publishes that owner's data fields. Keep AGUI persistence declarations on the application owner and use the standard data toolbar for session saving. HTML-app browser storage is independent and remains opt-in.
