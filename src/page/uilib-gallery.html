Filters and table

The independent filter publishes matching IDs; the table handles sorting, selection, and paging locally. Select-all includes matching leads on other pages and keeps selections outside the filter. This table does not edit its records.

Kanban

Drag leads between stages. Focus a card and press Alt+Left or Alt+Right to move it with the keyboard. The table above uses the same records and updates immediately. Unrecognized stages stay in Unassigned. Save commits record changes; Cancel restores the latest saved records. Table filters do not hide board cards.

Charts

The chart runtime loads when the first chart initializes. Select a bar or donut sector to share lead selection with the table. Each chart has a keyboard-accessible data view; the line example keeps its own selection. Missing values remain gaps and zero values stay meaningful.

Map

Select a marker or table row to share selection. Drag to pan, use the zoom buttons, or fit all mapped locations. Locations without coordinates remain in the table and are counted below the map. Tile requests go directly to OpenStreetMap; shared viewers see this viewport without interactive map controls.

Markdown

Use an external Markdown URL or edit the inline source. JSDA renders native HTML, highlighted code, and wrappers with readable fallbacks; registered components can enhance them. Document checkboxes remain disabled.

Data workflow

Edit Shared name, Shared status, Notifications, or lead stages, then use the floating bar. Save persists those values locally. Import replaces the draft, including the entire leads array; Cancel restores the saved values. Export includes unsaved edits.
